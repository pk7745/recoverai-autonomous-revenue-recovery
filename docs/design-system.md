# RecoverAI Design System Specification

## 1. Aesthetic Identity
- **Tone:** Enterprise Fintech Intelligence (Precision, Clarity, Bounded Autonomy).
- **Inspirations:** Stripe Dashboard clarity + Linear precision + Modern AI operational consoles.
- **Color Palette:**
  - **Backgrounds:**
    - Dark Canvas: `#0B0F17` (Deep Obsidian Navy)
    - Card/Surface: `#111827` (Rich Graphite)
    - Border/Divider: `#1F2937` / `#374151`
    - Elevated Surface: `#1A2234`
  - **Brand Accents:**
    - Primary Blue (Razorpay Royal): `#2563EB` / `#3B82F6`
    - Emerald Success (Revenue Recovered): `#10B981` / `#059669`
    - Amber Warning (Escalation / Review): `#F59E0B` / `#D97706`
    - Rose Danger (Stopped / Risk Block): `#EF4444` / `#DC2626`
    - Violet AI Intelligence: `#8B5CF6` / `#7C3AED`
    - Text Primary: `#F9FAFB`
    - Text Secondary: `#9CA3AF`
    - Text Muted: `#6B7280`

## 2. Typography
- Font Family: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`
- Monospace (IDs, currency amounts, signatures, hashes): `JetBrains Mono`, `Fira Code`, `ui-monospace`, `monospace`

## 3. UI Component Tokens
- **Cards:** Crisp 1px borders (`border-slate-800`), rounded-xl corners, subtle ambient backdrops.
- **Badges:** Pill-style status badges with glowing dot indicators (`RECOVERED`, `POLICY_APPROVED`, `ESCALATED`, `STOPPED`).
- **Data Tables:** Dense, sortable, responsive tables with clear monetary formatting (`₹12,450.00`).
- **Interactive Modals & Drawers:** High-contrast decision inspector drawer showing side-by-side: Diagnostic Signals -> Policy Guardrails -> Razorpay Execution Payload.
